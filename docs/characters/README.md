# 人物资料库与图像参考

从拼图右上角的猫形按钮进入人物索引。使用 hash 路由，刷新和静态托管均无需新增服务端重写：

| 地址 | 内容 |
|---|---|
| `/#/characters` | 角色索引，姓名/别名、作品、核对状态与已有详情筛选 |
| `/#/characters/wuxian` | 无限档案（对应独立 PR） |
| `/#/characters/xiaohei` | 小黑档案（对应独立 PR） |
| `/#/characters/nezha` | 哪吒档案（对应独立 PR） |

三个角色分别在独立分支面向 main 评审。共用页面与研究索引保持相同；每支只新增自己的角色 JSON 和图片，已安装档案自动加入索引，未安装的人物不显示无效详情入口。未知详情地址有返回索引入口。原拼图与旅程存档不迁移、不清除；原生 prototype 的离线入口保留。

## 角色名单的范围

[角色名单](CAST_INDEX.md)保留196条候选记录，覆盖 TV、众生之门、两部电影和《蓝溪镇》等公开目录。20条有官方人物页支持角色存在，176条社区目录线索保留待核。这个状态不等于详细设定或每项出场归属均获官方核验，也不等于待核角色不存在。不是官方完整角色册；未命名群众、组织和配音人员不当作单独角色。19条仅社区前瞻目录支持的学前篇归属单列未核作品，不宣称已官宣或登场。

鹿野是有效角色名。用户提到的“善心”未找到可靠同名角色；官方存在山新，但不能自动把二者改为同一名字。详见[研究报告](RESEARCH_REPORT.md)。

## 参考图与建模

每个角色先收5张完整图：不同形态、角度、服装或场景。图册支持放大、上一张/下一张、Esc或关闭按钮，关闭后焦点回到打开按钮。图片全部同站点提供，运行时不依赖第三方图链；既有节气图复用已有静态文件。每图记录原始页面、原图URL、作品/画面类型、观察用途、版权状态、字节数和SHA-256。

图片与角色版权归原权利人。公开可读不代表开放转载、训练或商业建模许可；没有将署名当作授权。正面立绘、动作截图和节气插图不是完整正交三视图；未知背面、准确比例和服装结构不自行补成官方设定。作品阶段、贺图年份和故事年龄分开标记。

## 维护与检查

`web/src/characters/*.json` 是各自档案及资源清单；`CharacterLibrary.jsx` 用Vite glob载入已安装档案。新增一个角色不必改共用注册表。`web/src/character-cast.json`保留所有候选名字与证据状态；新建正式档案须使用索引内相同ID。

```bash
npm --prefix web ci
npm --prefix web run characters:check
npm --prefix web test
node tests/scene-model.test.cjs
npm --prefix web run test:dom
npm --prefix web run build
CHARACTER=wuxian CHROMIUM_PATH=/usr/bin/google-chrome npm --prefix web run test:characters-browser
```

`predev`/`prebuild`继续核验拼图媒体，另核验人物图的路径、独立图像数量、HTTPS出处、字节数和SHA。缺损/修改的图片会让构建失败，不在构建时在线下载图片或生成音频。全部素材随对应PR进入Git，不提交收藏目录、模型或实验输出。

真实浏览器脚本覆盖桌面1360×940与触控模拟390×844、320×568，检查搜索/空态/状态筛选、直接地址与刷新、5图解码、图册翻页/关闭/焦点返回、未知档案和回到拼图后的存档保持。脚本阻断外部请求，截图每PR含桌面和手机多种状态；这是触控模拟，不代表实体iOS/Android或屏幕阅读器人工验收。原型DOM与模型检查单独记录，不混称真实浏览器验证。

## 页面设计

沿用四时拼图的松绿底`#edf3ec`、纸面`#f9fbf3`与墨绿`#24483f`，人物色仅用于名字和提示线（无限蓝灰、小黑深绿、哪吒暗红）。标题用本机宋体/思源宋体，正文用现有无衬线字体，不引入在线字体。桌面是图与人物档案并排、下接完整图册；手机改为纵向阅读。参考图保留全图，使用contain而非裁切来呈现造型；没有把美术图伪造为建模三视图。

## 本轮交付核验

三个独立分支均通过单元、模型、DOM、真实Chrome桌面/手机触控模拟与干净checkout构建。六种本地合并顺序均无冲突，组合版本通过单元测试和构建，识别3份档案、15个参考位置（14张不同图）。组合库另实测三卡并列和从人物卡进入详情。没有合并远端PR。哪吒分支另通过更正后的冬季六关桌面/手机实玩及36条MP3播放检查。
