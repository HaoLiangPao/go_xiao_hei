# 人物库之后的打磨顺序

| 阶段 | 内容 | 验收方式 |
|---|---|---|
| 本轮 | 第一部电影、电影2、众生之门、学前篇分别一个PR | 人物有出处；官方/媒体/社区线索分层；每PR有电脑手机截图 |
| 建模试验 | 先用猫形小黑、黑咻做简化练习模型 | 可转动、切换视角、做简单动作；导出通用模型后能重新打开 |
| 原声整理 | 从正版预告、特辑、片源逐句核听 | 台词、角色、语言、时间码、来源一一对应；不把采访声线当角色台词 |
| 声音改进 | 对比已有普通话合成与有明确使用许可的声音方案 | 小黑为男孩子的儿童声，无限更低沉；在电脑和手机实际试听 |
| 账号与存档 | 登录后保存个人进度；游客可玩且明确不保留账号进度 | 登录、退出、游客、换设备各状态可验证，现有本地存档有迁移说明 |
| 完成后下载 | 拼完才能下载原图或带拼图纹理的图 | 未完成不可下载；可选择尺寸并说明打印尺寸与清晰度 |
| 角色玩法 | 试验模型互动、动作收集、节气场景陪伴 | 先做小原型，确认效果再扩展角色 |
| 后续推广 | 小红书介绍、收集真实使用反馈 | 先打磨体验，再安排推广素材 |
| 更远期 | 实物拼图合作、淘宝店、收益捐赠工作室等 | 暂不实施；另行明确图像使用、合作与收益方案 |
