# 《借一盏灯》对白审阅稿

状态：待用户审阅。以下是声音模型接入前的短对白稿，尚未替换游戏里的完整文字，也没有生成或播放音频。

每次放好物件只触发一句角色对白，让声音回应操作。完整叙事保留为页面文字；音频旁白不重复把整段文字念一遍。第一版用获得许可的声音测试，不指定或克隆原配音演员。

| 触发动作 | 角色 | 待配音台词 | 表演提示 | 素材标识 |
|---|---|---|---|---|
| 瓦片放稳，漏雨停止 | 小黑 | 这里不下雨了。 | 先松一口气，再轻轻说；像发现一个小秘密 | `tile-set` |
| 热茶落在杯垫上，蒸汽升起 | 屋主人 | 这杯，留给赶路的人。 | 温和、自然；“这杯”后略停，不刻意煽情 | `tea-set` |
| 灯挂门边 | 小黑 | 这样，就不会踩空了。 | 认真地替别人考虑，尾音轻收 | `lamp-door` |
| 灯挂窗边 | 小黑 | 远远的，就能看见家了。 | 想象远处的人看到灯，轻微雀跃 | `lamp-window` |

可选尾声，第一版不自动叠加播放：“还有热的。”归人捧起茶杯后由小黑说。它需要新增明确的收尾时点，避免与挂灯对白重叠。

## 接入约定建议

- 玩家点击开启声音后再播放；有独立开关，静音不影响操作和剧情。
- 字幕与台词使用同一份文本。音频缺失或加载失败时，继续展示文本。
- 新剧情事件可播放；刷新、悬停颜色、查看参考、重读文字不自动重播。撤销后再次放置的重播规则需在接入时确定。
- 下一句开始前停止上一句，避免快速操作时叠音。
- 第一轮只生成四条短句并人工试听，确认音色、停顿和情绪，再扩大到更多台词。
- 本 PR 不新增声音服务依赖、API 密钥、音频素材或声音克隆代码。
