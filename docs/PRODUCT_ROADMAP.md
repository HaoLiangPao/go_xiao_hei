## 后续逐项实施

| 方向 | 用户期望 | 实施前需要明确 / 验收要点 |
|---|---|---|
| 角色声音研究 | 研究罗小黑视频/音频样本，比较现成声音模型或生成方案，尝试接近小黑、无限的原有声音 | 样本来源、可用授权和模型许可；分角色试听评审。下载、声音处理、训练和替换录音另开任务。本轮不执行 |
| 角色建模 | 在适合的软件中建模人物，让后续原创内容有更多可能 | 软件、2D/2.5D/3D目标、角色范围、设备资源和导出格式；先做一个可评审角色。之前提到的软件未在当前记录中确认为最终选择 |
| 账户登录 | 各人的状态能保存，换设备继续 | 身份服务、隐私与状态范围：关卡/区域/片数/设置；匿名旧存档迁移、同步冲突和退出登录验证 |
| 游客模式 | 游客直接玩，但不保存状态 | 需确认“不给账户云保存”还是“连本地持久化也不留”；决定刷新、关页后行为，并向游客清楚提示 |
| 版权说明 | 声明罗小黑原图、人物等版权归原权利人 | 明确非官方二创；列来源和反馈/下架渠道，区分自写剧情与原作素材。署名不视作转载、配音或商业授权 |
| 通关下载 | 只有拼完图才可下载 | 未通关不展示下载操作；只认可本张图完成。访客/账户条件、重新开局后的下载资格另明确 |
| 下载样式 | 可选原图或完成后的拼图效果图 | 两种导出预览，拼图接缝/阴影不破坏画面；文件命名、来源/版权说明；手机保存与分享验证 |
| 下载尺寸与打印 | 多种尺寸，方便自己打印 | 明确像素、比例、纸张/打印尺寸和清晰度提示，避免把放大当作新增细节；测试透明边缘、接缝和裁切 |
| 更多年份 | 以后继续其他年份节气图 | 核对来源、完整性、授权、跨年选择与独立进度；缺图有明确状态，不推断“官方没发布” |
| 推广与反馈 | 先在小红书介绍，让人开始使用，再逐步发展 | 准备桌面/手机演示与反馈入口；根据实际使用问题安排下一项功能，避免提前堆叠功能 |
| 实物拼图合作 | 将来考虑淘宝等拼图店，使用图片制作实物 | 暂缓。确认图像商业许可、合作方、质量/交付、售后及费用安排后再单独讨论 |
| 收益捐赠 | 如有收入，考虑捐给罗小黑工作室 | 暂缓。先确认权利人/接收方意愿、收入与成本口径、捐赠流程和披露方式；不预先对外承诺 |

## 下载保护的实际边界

当前图片是同站点公开静态资源。前端“拼完才显示下载”能控制正常使用流程，不能保证未通关者无法通过开发者工具或图片 URL 取图。若需要严格限制原图访问，需另设计服务端授权、资源存储与访问控制，不能把前端按钮锁定当作安全保证。

## 实施顺序与评审

先完成并评审三个 2020 季节 PR，再逐项选择下一功能。原声研究和建模是探索方向；账户、游客、版权、通关下载可分别形成可评审任务，不在季节内容 PR 中混做。所有新功能都准备 PR；远端创建若受阻，保留提交、PR 正文及可由用户直接执行的 push / gh pr create 命令。未明确授权不合并、不主动发布生产。
