# 像素街区：第一块可走动地图

本轮只做一块独立可玩的街区，保留现有拼图与3D模型。入口 `/world/`；独立静态页面可用 file:// 离线打开。

山新家、小白家、小白爷爷家是用户指定的地点。建筑外观、相对位置和门口片段为本项目原创试作，不声称复原官方地图、房屋设定或原作台词。小黑以既有人物图册 `web/public/art/characters/xiaohei/reference-1.png` 右下猫形为主参考；侧背面是保守的像素试作。

色板：草地 #9bad6b，树叶 #52734d，深轮廓 #28352b，小路 #d7bd87，河水 #6ca7a2，眼白 #f7e6bb。建筑用青绿、灰紫、棕红屋顶区分，统一光源、像素密度与轮廓。

字体：系统中文黑体负责导航和可读说明；地图及精灵使用整数像素，最近邻显示，不依赖网络字体。32×32猫形精灵四个朝向，共四帧行走，脚底为锚点；这是试作尺寸，不是《星露谷物语》的官方规格。

布局以地图为主体，右侧为整块街区的小地图、三户目的地及拜访记录。手机将方向键与拜访操作放在地图下方，目的地仍可点选。避免把游戏切成重复卡片，也不让三户房屋变成传送按钮：选择目的地后，小黑沿真实可走路径前往门口。

```text
街区名 / 回到拼图
┌─────────────────────┐  街区小地图
│ 地图跟随小黑         │  去山新家
│ 草地 / 房屋 / 河桥   │  去小白家
└─────────────────────┘  去爷爷家
当前地点 / 敲门            本次拜访记录
手机方向键 / 停下
```

对照需求后的选择：用连通道路、可阻挡的河流/房屋和四向角色建立真正可走动空间；先做好这一块场景，不扩展种田、背包、室内、账号或原声。行走帧属于动作反馈；不加自动漂浮、闪光和与操作无关的动画。尊重减少动态效果，仍允许主动移动。

检查需要包括路线连通、碰撞、失焦松键、对话暂停、小屏触控和原有存档保留。视觉检查必须实际查看原参考、精灵图册及电脑/手机场景，功能测试不能替代美术判断。
