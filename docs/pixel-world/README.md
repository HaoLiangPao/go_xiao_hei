# 小黑的像素街区

独立地址 `/world/`，也可从拼图底部“像素街区”进入。直接打开 `web/public/world/index.html` 可离线运行，不需构建，不访问CDN，不下载素材或字体。现有3D模型与拼图玩法不变。

| 这一版可做 | 行为 |
|---|---|
| 小黑四向行走 | 32×32猫形像素精灵，每朝向4帧，脚底固定；镜头随角色移动 |
| 三户人家 | 山新家、小白家、小白爷爷家；不同屋顶颜色帮助认路 |
| 自由走动 | 键盘方向键/WASD、手机按住方向键，或点地面寻路 |
| 去朋友家 | 点目的地后实际沿可走区域步行；去爷爷家需经过小桥 |
| 拜访 | 到门前敲门，出现原创小片段，本次拜访数从0到3；对话时暂停走动 |
| 中止与回退 | 可随时停下；抬手、取消触摸、页面失焦均释放输入；回到拼图保留旧存档 |

房屋、河流与树干有碰撞，草地可以走；花圃与小石头目前是地面装饰。没有室内、种田、背包、账号或持久化世界存档。拜访记录只留在本次页面，刷新清空，未使用或迁移任何已有拼图存档。

这是原创街区玩法示意，不是官方地图复原。三处地点由用户指定，建筑外观、相对位置和门口短文为本项目原创；没有把文字伪装成原作台词。人物与原作形象版权归原权利人，未使用《星露谷物语》的图片、地图或音频资源。没有改动现有3D模型或新增声音模型。

美术以既有人物图册 `web/public/art/characters/xiaohei/reference-1.png` 右下猫形为主参考；侧背面是像素试作，不声称已有官方四向设定。地图和角色均以代码绘制整数像素；地图按1或2倍、图册另提供4倍最近邻放大。中文导航使用系统字体，属于界面文字，不属于像素精灵。

验证方式：

- `npm --prefix web test` 包括纯地图检查：三家连通、桥梁路线、绕墙/河、连续移动及大步长碰撞；不代表美术通过。
- `node tests/scene-model.test.cjs`，`NODE_PATH=web/node_modules node tests/color-interaction.test.cjs` 保留旧场景和DOM检查；DOM检查不覆盖渲染与触摸。
- `npm --prefix web run build`，`npm --prefix web run test:world-browser`。后者在Chrome 1360×940、390×844、320×568检查实际Canvas绘制、多个行走帧、键盘、到三家步行/拜访、过桥、点地面、停下、对话暂停、页面宽度和拼图存档。
- 手机使用Chrome触控模拟：真正按住触点跨越多个动作帧，再取消触摸核对停步；不是实体手机或移动GPU测试。失焦为事件模拟检查，不声称系统切换窗口实测。另检查方向按钮的键盘按住/松开、停止后继续用方向键，以及门牌保持在画框内。
- 另检查直接file://离线无网络请求、减少动态效果时仍能移动但不循环步态。

截图在 `docs/screenshots/pixel-world/`；`xiaohei-atlas.png` 为原始128×128精灵图册，`xiaohei-atlas-4x.png` 为整数4倍最近邻。行从上到下为正面、右、背、左；列为4个行走帧。截图本身不证明连续动画审美或实体设备体验。

代码：`world-model.js` 负责纯地图、碰撞和寻路；`world-art.js` 负责原创地块及角色绘制；`world.js` 负责输入、镜头、交互和渲染。无新依赖或构建步骤。

## 美术审核与兼容性

[初审](ART_REVIEW_INITIAL.md)限定通过静态角色辨识度和场景画风，并指出步态、耳尾和门牌的P2建议；[局部复审](ART_REVIEW_REVISION.md)确认这四项修订在已查看的图册和电脑/手机位置中改善成立。三户房屋外观相似性保留为后续P2；连续步态节奏、脚滑、转向与镜头像素稳定性仍为INCOMPLETE，审阅工具只显示GIF首帧，没有假称已观看连续动画。

`walking-demo.gif` 为真实Chrome中按住方向键连续行走的录制：按真实时钟每100ms取Canvas无损帧，以2倍最近邻生成动图。编码优化后小于1MB，原生像素不经视频压缩。初版复审所核对的59帧视频转码版本固定在提交0cf950b；优化后动图61帧，world源码及PNG图册不因这次录制/编码变化。它是可观看的演示，不把录像采集方式作为独立动画美术通过的证明。

file://模式的返回链接指向现有 `prototype/puzzle.html` 离线拼图，页面明确写“回到离线拼图”；它使用原有独立存档，不和网页版存档合并或迁移。在线模式仍回到当前网页版，并验证显示3/12与保存的三片不变。
