# 像素街区首块玩法小样独立美术审核

**结论：PASS，限定于首块小样的静态像素方向、基本角色辨识度及已给画面中的角色/环境一致性。** 大黑瞳、浅色眼环、绿色内耳、蓝绿小嘴和黑绿身体保留了猫形小黑的主要线索；角色与低饱和草地、米黄墙面、屋顶及树木处于同一块面与描边语言中。当前没有足以否决这块静态试样的主要辨识度问题。

**完整连续行走审核为 INCOMPLETE。** 四向图册有提供，但步态变化很弱；没有独立连续播放证据，不能确认循环节奏、脚滑、转向瞬间及相机移动中的像素稳定。下述 P2 建议保留，不把静态方向通过扩大成完整游戏美术、原作精确还原或用户最终认可。

## 分项判断

| 项目 | 可观察事实 | 审美判断与证据边界 |
|---|---|---|
| 正面辨识度 | 两只大黑瞳被浅米色眼环包围，脸部大面积为眼睛，黑绿短身体，耳内绿色，小嘴蓝绿；桌面与390px默认画面仍看得到眼耳结构 | 主要线索成立，读起来是小黑的像素改编。像素取舍不必复制原作每一根轮廓线；没有显著“只剩通用黑猫”的问题 |
| 头身与姿态 | 头大、躯干短，腿/脚位于下部，方向变化保留大头短身关系；正面与背面头宽接近，侧面按方向变窄 | 首块俯视街区小样可以接受。参考是坐姿，候选是行走站姿，不能直接用其全身高度比例判错 |
| 像素轮廓 | 图册边缘为清楚的方形色块，眼形有可辨的阶梯转折，没有新增半透明抗锯齿毛边；黑/棕描边与较亮地面形成分离 | 像素表达成立。耳尖偏方柱是风格取舍中的可改善项，见下表 |
| 色板与环境 | 角色黑绿、棕框、米色眼环呼应树木深边、土路及墙面；环境使用低饱和绿、青、米黄和暖棕，屋顶靠青/紫灰/暖棕分区 | 角色没有突兀的写实高光或矢量渐变，基本风格一致；角色比环境更深是可读性需求，不是色板不统一 |
| 四向体积 | 图册各朝向耳、头、身体占幅稳定，同一行四列头部保持稳定，没有明显一帧突然鼓胀或缩头 | 可以确认这些静帧的基本体积稳定；不能由静帧确认转向过渡时没有跳变 |
| 脚底锚点 | 各行四列脚底落在相同基线，未见单帧整体垂直错位；变化集中在腿部，很小 | 静态脚底基线稳定；锚点一致不等于走路自然，脚滑仍待连续播放判断 |
| 手机可读性 | 390px及320px抽查中，角色仍能从草地和路面上分离，正面能看两眼，侧面能看单眼，门与道路清楚；对话文字可读 | 角色基本可读。耳内绿、嘴和尾巴属于很小的次级细节，手机不能期待与图册放大时等量的信息 |
| 三屋与场景组织 | 三座房子拥有一致墙窗和屋顶结构，靠屋顶颜色、门牌、所在岸边区分；桥与道路接续关系在画面中明确 | 适合验证街区方向，但目前主要是同一房屋模板变色，角色居所个性还弱。这不是官方场景还原失败 |
| 对话框风格 | 米色底、深绿色文字、方形细边与场景低饱和色板协调，桌面与手机文字都能看清 | 不使用像素中文字体也不构成缺陷；清楚阅读优先。未由截图判断点击、关闭或焦点行为 |

## P2改进项及不确定性

本轮未列 P1；下面是继续完善小样的有限建议，不表示必须把所有装饰做完才能让用户试走。

| 优先级 | 位置与证据 | 具体问题/判断 | 建议修改 | 复核证据 |
|---|---|---|---|---|
| **P2，优先** | `xiaohei-atlas.png` 与4倍图册，四行全部 | 四列步态变化很弱：头、躯干和脚底轮廓几乎相同。视觉观察后对原图像素补充比对，确认每行第1列=第3列、第2列=第4列，变化仅集中在腿部两行。因此目前是两个很接近的姿态重复，并非四个独立姿态。两姿态循环本身不是错误，但这里步子不容易读出来 | 不扩大图册尺寸，先做一行侧面试样，明确前后脚的交替与摆动/接触关系；保持躯干体积与底部锚点。不要靠全身上下跳动代替迈步，也不要求强行增加为4个独立姿态 | 原尺寸与4倍图册修前/修后，以及侧向连续走一段。判断是否仍像滑动，需要连续证据 |
| **P2** | 图册正面、街道正面 | 耳尖最外段为直立方柱，绿色耳内也是较竖直的小块，猫耳斜边的读法弱于主参考 | 仅尝试在现有网格中修少量斜阶梯，让耳尖与耳根形成更明确的三角关系；不一口气把耳朵加大加长 | 正、侧、背同倍率一组，同时看390px地图内原大小，防止放大好看而默认尺寸丢形 |
| **P2 / 待选** | 图册正面、侧面与 `mobile-walking.png` | 尾巴靠近身体，弯曲关系不强，默认尺寸容易读成旁边短肢；侧脸小嘴也只是极小色点 | 可以先尝试稍明确尾巴外轮廓的弯曲或与躯干间的负空间，保留小嘴为辅助线索即可；不增加毛发、复杂抖动与细碎单像素装饰 | 四向默认大小与最近邻放大并排；没有原作完整四向设定，不规定尾巴唯一长度和方向 |
| **P2，场景个性** | `desktop-shanxin/xiaobai/grandpa.png` | 除屋顶配色和门牌外，三屋的墙窗布局相当接近 | 每屋最多先增加一个小而清楚的原创外部线索，如独特花盆组合、门边物或窗帘差异。明确属于原创示意，不把新设计写成原作设定 | 三屋同尺度对照、手机默认大小。不要用大量细小杂物提高密度 |
| **P2，显示边界** | `mobile-street.png`、`mobile-shanxin.png`、`mobile-xiaobai.png`；320px抽查 | 上方房屋门牌会贴近甚至被地图画布上边缘截去一部分；右侧被视口裁切的房屋标签也会不完整。列表仍能给出目的地，但场景内门牌的完整可读性不稳定 | 可先让目的地/附近房屋标签避开画布边界，或仅在足够显示空间时画完整标签；房屋本体可以自然出画，不必强行把整张地图塞进手机 | 同位置桌面、390px和320px；不用由变大字号或改变相机掩盖角色本身的可读性 |

像素补充比对针对的是已经查看的实际图册像素，用于确认帧的重复与差异位置，不是根据实现参数推测画面。脚底静态不动可能是有意锁定接触点；只有连续播放才能判断是否形成自然行走，不能仅以“两帧重复”判动画失败。

## 下一轮最小范围

1. 先保留当前地图与角色尺寸，只做**一行侧向步态**的可比较试样，让迈步清楚，同时保持体积和脚底锚点。
2. 提供正面及侧面各一段短连续走动，包括起步、匀速、停止与一次转向；同时给原尺寸/4倍最近邻图册。没有连续播放证据时继续标为待确认。
3. 门牌边界可以单独做局部显示修正。耳尖、尾巴、三屋个性作为之后的少量变体，不建议这一轮重画全部角色或扩建新地图。
