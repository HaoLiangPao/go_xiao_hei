## 最小下一轮

先只做三组改动：**脸与眼的占比、耳根/耳高、前后肢连续性**。这是最可能改变“像不像”的三组，优先于添加动作、特效与材质细节。小三角嘴可以随脸部一起补入，但应保留同一默认表情。

交付前后对照时，锁定相机、角色屏幕高度、画布大小、光照和静止时间点，至少给出正面、四分之三、侧面、背面；再给390×844下同一默认视角。现有页面截图滚动位置不同，不应靠页面占幅直接判断模型变大或变小。

将参考 1 猫形裁切、d856794 初版和下一版按等高并排，首先看“眼睛是否支配脸、耳朵是否连入外轮廓、四肢是否从身体长出来”。可以另加纯轮廓图辅助，但不允许只凭轮廓掩盖脸部和材质问题。三项若只有部分改善，继续要求修改，不把“改了很多”当通过理由。

## 对 character-art-review skill 的检验

这份 skill **足以引导出具体证据，且能避免把功能通过写成审美通过**。本轮按它实际查看3张参考与5张候选，能够定位到眼脸占比、耳根、厚眼片与球状四肢；它明确禁止只读参数/日志，也要求缺乏动作或背面证据时保留待确认。这些条款实际约束了本轮输出：没有给动作、触控、原作背面或黑咻细部判 PASS。

以下补充会让下一轮更可重复；本轮只提出意见，没有修改 skill：

| 建议补充 | 为什么有用 |
|---|---|
| 每轮显式指定一张“主参考”，电影/TV其他素材只作辅助 | 避免将电影透视、TV趴姿和正面立绘揉成不存在的统一标准 |
| 要求保留同机位、画幅、屏幕高度、灯光与动作时间点的前后图 | 防止镜头变化制造“改善”，也防止把透视差异误判成比例错误 |
| 缺证据的范围单独列 INCOMPLETE，不因整体结论是 CHANGES_REQUESTED 就省略 | 使下一轮知道哪些是要改，哪些只是要补证 |
| 每个主要问题强制写“观察—判断—不确定性—复核画面” | 当前格式已经接近这个目标，显式约束可减少“更自然、更可爱”一类空话 |
| 引导保留初版对照，不能只看最新渲染 | 便于确认哪项确实改善、哪项被材质或镜头遮住 |
