# 练习桌的设计

以用户现有四时拼图的绿色、安静字体和留白为基础，把注意力留给可转动的角色，避免额外的仪表盘信息。

色彩：纸面 #f1f3ed、桌面 #e4ece1、深绿文字 #254840、操作色 #365d51、黑色模型 #101c18、浅绿眼白 #e8ffd0。

字体沿用中文宋体/衬线字体。电脑左侧放较大的转台，右侧放名字、动作与下载；手机将同样的操作顺序排成一列。回看正面/侧面/背面与缩放始终有按钮可用，不依赖拖动才能操作。

画面只突出一件东西：深色角色和浅色眼白落在一个有阴影的小转台上。动作由用户主动触发，不自动转圈或持续蹦跳。初版检查后，去掉手机默认蓝色点击高亮，保留键盘可见焦点。
